# Tesi Angelo Russo

Repository contenente il codice Python e i dataset utilizzati per la tesi di laurea triennale.

## Titolo della tesi

Applicazione di tecniche di Machine Learning alla previsione del passaggio dei gironi nel Mondiale FIFA 2026.

## Contenuto del repository

- `main_finale.py`: codice principale utilizzato per la preparazione dei dati, l'addestramento dei modelli, la valutazione sul Mondiale 2022 e la simulazione del Mondiale FIFA 2026.
- `grafici_tesi.py`: codice utilizzato per generare grafici e tabelle presenti nella tesi.
- `grafico_gironi_finali.py` : codice utilizzato per generare le tabelle dei gironi contenenti la classifica finale di ogni girone del Mondiale 2026 
- `training.csv`: dataset utilizzato per il training e il test dei modelli.
- `predizione_2022.csv`: dataset utilizzato per la simulazione della fase a gironi del Mondiale 2022.
- `test.csv`: dataset contenente le squadre considerate per il Mondiale FIFA 2026.
- `prediction_2026.csv`: dataset finale utilizzato per la predizione delle partite del Mondiale 2026.
- `simulazione_gironi_2026.csv`: risultati finali della simulazione dei gironi del Mondiale 2026.

## Note sui dataset

I dataset sono stati costruiti a partire da fonti pubbliche disponibili su Kaggle e successivamente modificati, integrati e riadattati agli obiettivi della tesi.

## Librerie principali utilizzate

- pandas
- numpy
- scikit-learn
- imbalanced-learn
- xgboost
